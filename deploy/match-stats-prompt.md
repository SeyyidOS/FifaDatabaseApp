Read the Matchnight match-stat photos that have not been read yet and save their numbers.
`{script}` is the stats script; run it exactly as written below.

1. Run `python3 {script} pending --new`. If it prints nothing, stop: say "İşlenecek fotoğraf yok." and end.
2. Each output line is JSON: board, matchId, photoId, time, clubA, clubB, scoreA, scoreB, teamA, teamB, image (a JPEG path). Open each image with the Read tool. A match may have several photos; one summary screen is enough per match, and once a match is saved skip its other photos.
3. Only the game's match summary screen counts: the "Özet" tab, with the score at the top, a table of rows in the middle and three percentage rings on each side. Skip any other photo (other tabs, people, blurry shots) and note why.
4. Read both columns of the table. The rows map to these keys: Topa S. Olma %'si → possession, Topu Geri Kazanma (Saniye) → recoveryTime, Şutlar → shots, Gol Beklentisi → xg (decimal comma: "2,42" is 2.42), Paslar → passes, Müdahaleler → tackles, Başarılı Müdahaleler → tacklesWon, Top Kesmeler → interceptions, Kurtarışlar → saves, Yapılan Fauller → fouls, Ofsaytlar → offsides, Köşe Vuruşları → corners, Serbest Vuruşlar → freeKicks, Penaltı Vuruşları → penalties, Sarı Kartlar → yellowCards, Kırmızı Kartlar → redCards (only if shown). The rings on each side: Başarılı Dribbling Oranı → dribbleSuccess, Şut İsabeti (%) → shotAccuracy, Pas İsabet Oranı → passAccuracy. The left column and the left rings belong to the club shown left of the score.
5. Map the columns to the app's sides: A is clubA with scoreA, B is clubB with scoreB. The game may show either one on the left, so match them by club name and score. The game's names can differ from the app's ("Milano FC" is AC Milan, "Spurs" is Tottenham Hotspur, "FC Bayern München" is Bayern Munich, "Stade Rennais FC" is Rennes, "PSG" is Paris Saint-Germain). If the clubs or the score do not fit the match either way round, do not save it; report it instead.
6. Leave out any number you cannot read with confidence; never guess. Before saving, check: possession A + B = 100; shots × shotAccuracy / 100 is close to a whole number; tacklesWon ≤ tackles. If a check fails, look at the photo again, and leave that number out if it stays unclear.
7. For each match, write {"board": ..., "matchId": ..., "photoId": ..., "A": {...}, "B": {...}} with the Write tool to a file named `match-<matchId>.json` in the folder of the images, and run `python3 {script} submit <that file>`.
8. Do not change any code, commit, push or open pull requests.
9. Report briefly in Turkish: which matches got stats (clubs and score), which photos were skipped and why, and any number you left out.
